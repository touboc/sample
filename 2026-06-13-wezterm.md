Here is a cheat sheet of the standard, out-of-the-box keyboard shortcuts for **tmux**.

Remember, for every single one of these shortcuts, you must first press the prefix key—which defaults to **`Ctrl+b`** in tmux—release it, and then hit the shortcut key.

## 1. Session Management

Sessions are the highest level container in tmux. They keep your work alive in the background even if your internet drops or you close your terminal window.

|**Shortcut**|**Action**|
|---|---|
|`s`|List all active sessions (use arrows to switch between them)|
|`$`|Rename the current session|
|`d`|**Detach** from the current session (leaves everything running safely in the background)|

## 2. Window Management (Tabs)

Windows in tmux act exactly like tabs in a modern web browser.

| **Shortcut** | **Action**                                       |     |
| ------------ | ------------------------------------------------ | --- |
| `c`          | Create a new window (tab)                        | o   |
| `,`          | Rename the current window                        |     |
| `n`          | Move to the **n**ext window                      | o   |
| `p`          | Move to the **p**revious window                  | o   |
| `0` to `9`   | Move to a specific window by its index number    | o   |
| `&`          | Kill (close) the current window                  | x   |
| `w`          | Interactively choose a window from a visual list |     |

## 3. Pane Management (Splits)

Panes allow you to split a single window into multiple terminal grids side-by-side.

| **Shortcut**  | **Action**                                                                   |     |
| ------------- | ---------------------------------------------------------------------------- | --- |
| `%`           | Split the window **vertically** (creates a pane to the right)                | o   |
| `"`           | Split the window **horizontally** (creates a pane below)                     | o   |
| **Arrow Key** | Move your cursor to the pane in that direction                               | o   |
| `o`           | Cycle cursor focus through all open panes                                    | o   |
| `;`           | Toggle between the current pane and the last active pane                     |     |
| `z`           | **Zoom** the active pane to full screen (press again to unzoom)              | o   |
| `x`           | Close the current pane                                                       | o   |
| `Spacebar`    | Cycle through preset pane layouts (even grids, rows, columns)                | o   |
| `Ctrl+Arrow`  | Resize the current pane in that direction (hold `Ctrl+b` and tap arrow keys) |     |

## 4. Copy Mode & History Scrolling

Because tmux controls your terminal window, you cannot use your mouse wheel to scroll up through your command history by default. You have to enter **Copy Mode**.

|**Shortcut**|**Action**|
|---|---|
|`[`|**Enter Copy Mode** (you can now use your Arrow/Page keys to scroll history)|
|`Spacebar`|Begin selecting text (while in Copy Mode)|
|`Enter`|Copy the selected text into the tmux clipboard and exit Copy Mode|
|`]`|Paste the text you just copied|
|`q`|Quit Copy Mode without copying anything|

## 5. System Commands

| **Shortcut** | **Action**                                                                       |
| ------------ | -------------------------------------------------------------------------------- |
| `?`          | List all available tmux shortcuts inside the terminal                            |
| `:`          | Open the tmux command prompt line (to type manual commands)                      |
| `t`          | Show a massive digital clock in the center of your pane (press any key to close) |
