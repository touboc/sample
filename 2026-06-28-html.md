# ⭐ Why this template works

- The **role block** forces the model into the correct expertise.
- The **task block** defines the transformation target.
- The **constraints block** enforces:
    - Obsidian‑accurate highlight color
    - No `<p>` tags
    - Visual fidelity
- The **output block** ensures the model returns a complete HTML page.
- The **content block** makes it reusable for any Markdown snippet.
